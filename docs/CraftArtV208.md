# V208 造物重设计、重绘与炉内承托修正

2026-11-21。依据制作人“请你修改”和《造物美术一致性审查》的具体建议实施。六类、十一档及经营规则保留；本轮交付为已接入的新版素材、完整运行前后对照和验证记录，供制作人审查画面。

## 玩家看到的变化

| 品类 | 本轮主要变化 |
|---|---|
| 机关鸟 | 木雀、信鸽、展翼信隼、信鹤以翼形、尾形、信筒和信篮区分；高阶保留机关与传信特征，收敛凤凰长羽、金饰 |
| 守门石狮 | 以坐、立、抬爪、踏珠、伏守与简洁门槛区分，狮体保持主体；高阶宫殿式大基座改为低石台、护门石 |
| 随身洞府 | 石屋、住屋、合院、廊桥、重楼与家园，强化可居住空间；归纳屋面和岩石，减少金门、悬浮山与密集殿顶 |
| 机关驮兽 | 用驮包、双篓、货架、双箱、卷料、桶、篷布与重载货物区分；高阶保持可辨兽身和四肢，背部建筑改为运货结构 |
| 守御建筑 | 保留望哨、门楼、关隘、城塞轴线；用主要防守构件区分，减少金边、逐砖逐瓦和层叠宫殿屋顶 |
| 石泉水脉 | 用泉口、双眼、裂岩、双瀑、水渠、连池与三叠水区分；高阶回归岩、水、渠、池，移除宫苑楼阁 |

## 画法与制作依据

直接参考项目真实丹坊场景、既有淡彩勾线要求及已认可人物的归纳画法。先生成机关鸟，在炉内检查1/15/100转，再以同一线条与色块处理扩展五类。采用细棕轮廓、哑光木石与少量旧铜、大片固有色和克制主阴影；减少硬金属高光、珠宝式边缘、密集雕纹。高阶各自保留传信、守门、居住、运货、防守、供水用途。

使用**内置imagegen**，最终原图与运行图保存于发布目录 `assets/crafts/`：`bird/lion/home/beast/tower/spring.png`为母图，同名`.webp`为运行图，`frames.json`记录66个轮廓矩形。完整提示集、风格参照、生成原文件和驮兽贴边修正记录见同目录`provenance.md`。旧V206/V207资源保留。

只进行alpha分析取图标定和无损WebP文件编码，解码RGBA逐像素等于最终生成PNG，未用代码调色、补画、缩放或改alpha。六张运行图约5.80MB，V207约7.53MB；第8档驮兽首稿贴边，使用imagegen定向修正，最终六图均有11个完整主体且不触及母图外边界。编码与分析记录见`asset-checks.json`。

## 炉内承托与交互

- 按实际造物轮廓高度定位底部，底部固定在投影炉内接触面，改变阶段比例时不以统一圆形中心造成脚底漂移。
- 深色硬椭圆改为轻柔渐隐接触投影，宽度按品类的支撑轮廓归纳，始终裁在炉内范围。房间与炉前使用同一投影坐标和承托计算。
- 命中区域跟随显示对象。持物时不画落地投影，取消恢复，拖入真实收取目标后正常入匣。
- 普通丹药的图像、位置与原投影分支保持；没有新增面板、成长奖励或额外操作。

现有标准C04的二维淡彩勾线要求和C05的同房间承托、落影、遮挡要求作为本轮依据。功能、内部画面对照和制作人美术认可分别记录，不以脚本通过代表制作人验收。

- 受影响脚本语法、路径、差异格式与反馈规格校验通过。照片脚本13张完整运行截图，无页面错误。
