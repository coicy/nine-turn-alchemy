# 开局信息减负 V53

日期：2026-10-31。依据试玩反馈：“能玩，但是界面信息一开始就太多了，容易炸脑”。

## 本轮体验变化

- 开始页减少经营规模与规则重复，三幕演出缩为一幕，保留跳过与自愿试玩记录选择。
- 第一份委托结束前默认仅突出炼丹台；可随时点“查看全部功能”。无论首单成功、失败或终止，结束后显示原有经营入口。展开偏好保存在本浏览器，清除浏览器数据后重置。
- 首单隐藏空法器槽、钱包与品质、重复丹值；保留转数、炸丹概率和“收丹后交付／差额／未投药材”。没有调整随机概率、目标或收益。
- 投药、首次炼化、继续或收丹使用当前步骤提示；拿起物件、选择丹纹、炼化等待优先使用对应操作提示。
- 丹纹效果改为出现丹纹后可展开查看；坊市组合说明默认折叠，仅列已开放或已购法器。
- 修正九转须收丹、全部订单处理完才可日结、去坊市选择丹纹等旧提示。
- 首单炼化结果提示下移，避免挡住交付读数。
