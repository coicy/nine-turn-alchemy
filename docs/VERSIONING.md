# 九转丹坊版本管理

## 当前基线

- 当前产品版本：`V219`。
- 基线提交：`5541641`。
- 基线标签：`release-v219`。
- 当前发布入口：项目根目录 `index.html`。

## 命名规则

- 产品版本使用根目录 `VERSION` 统一声明。
- 正式交付使用 `Vxxx` 产品版本号、Git 提交和 `release-vxxx` 标签共同标识。
- 运行脚本、样式和当前资源使用稳定用途名称，不再把专项迭代号写入文件名。
- 历史专项编号只保留在 `docs/`、验证记录、变更日志和归档资料中。

## 迁移规则

- 重命名前先扫描 `index.html`、运行脚本、样式和验证脚本的引用。
- 当前运行入口只允许引用稳定名称；历史资料不得反向成为运行依赖。
- 旧实现只有在当前入口、运行逻辑和验证工具均不再引用时，才可移入归档或删除。
- 版本迁移不得混入未审查的业务代码修改；未提交的业务文件必须单独处理。

## 发布验收

- `VERSION`、Git 标签、发布记录和线上部署提交必须指向同一产品版本。
- 发布前执行资源路径、脚本语法、核心玩法和浏览器页面检查。
- `docs/` 与 `qa/` 保存交付说明和验证证据，不作为当前运行文件的替代版本。
