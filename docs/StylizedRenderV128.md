# 二维手绘化 V128

丹房与炉前的固定镜头改用直接绘制的二维画面，统一暖墨勾线、淡彩色块和材质笔触。炉盖云钮、炉胆、书册、木器及地面同步处理，保留同一房间的家具位置和透视。

覆盖电脑／手机、丹房／炉前及开盖／合盖八张背景，另有四张与新背景同色的透明前沿。运行仍使用二维图片；模型只用于空间与遮挡约束。UI继续沿用纸木、必要短文字、五项准确概率、常驻库存和直接取料。
