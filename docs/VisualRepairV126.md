# V126 美术与界面修复

2026-11-08。基于制作人对V124画风与UI退步的反馈实施。

## 本轮变化

- 恢复冷灰环境、灰米陶、灰青盖与旧木的区分，重绘同一场景母稿；降低墙地细碎纹理，使当前操作与判断更突出。
- 在共同空间中精修内外釜分层、拱盖及云钮、布药囊、书册纸页与装订；柜内书册、标签和药束补充使用感，不增加操作系统。
- 重绘17件法器图像，统一描绘方式与承托；新图用于工作区、装备详情和既有商品显示，身份及业务定义不变。
- 顶部使用图标配短字，统一纸木配色、按钮状态、需求印记和朱砂收丹按钮；完整丹值、转数与五类准确概率保持炉旁可读。
- 常驻库存改为紧凑的纸木区域，物件图、数量角标和选中轮廓统一；空丹药行撤下，直接取料和单击查看库存丹药保留。
- 合盖时盖座不留画死炉盖；炉中丹继续按前沿遮挡，持物取消与阅读返回保持同一炉。

## 来源与边界

图像使用内置imagegen工具，源稿与完整提示词保存于项目Art/VisualRepairV126；最终运行资源在assets/scene-art-v126。运行仍为预渲染图片，不向手机增加WebGL。两视角与开合盖共享同一模型，家具位置、尺度和通道关系不为UI独立重排。

本轮未改炼化、概率、计价、经营、装备条件和存档。旧委托收丹仍自动计入委托；统一成丹入库／明确提交等独立业务待办不在本轮完成。

本地与线上状态以Evidence/VisualRepairV126/release.json和Proof.md为准。资源一致性、操作回归与局部对比采样不代表制作人最终美术、真机手感或新玩家理解已经验收。
