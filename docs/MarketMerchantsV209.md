# 坊市摊主
玩家进坊市时先见何采药的药包，可以直接选另一块摊牌。法器商有法器与改炉两架，周掌柜出售六类造物器料。接受柜台邀请会直接看法器商的避火佩。逛摊、看货都免费，只有在货签上确认购买才扣款入账。

## 接入一位摊主

在 `market-merchants.js` 的 `merchants` 数组追加一项。每位摊主使用唯一 `id`、显示名、项目内立绘相对路径与货架列表。可选 `fromDay` 为最早出摊日，默认第一天。下例是开发示例。

```js
{
  id: 'travelling-supplier',
  name: '游商',
  portrait: 'assets/customers-v61/merchant.png',
  fromDay: 4,
  shelves: [
    {kind: 'craft', ids: ['bird', 'lion']},
    {kind: 'tool', ids: ['stone']}
  ]
}
```

| 货架 | 可配置货品 |
| --- | --- |
| `material` | 药包索引 0、1 |
| `tool` | 现有法器 ID，随营业日开放，已持有的法器可回看 |
| `furnace` | `upgrade`，按当前炉具等级提供下一次改良 |
| `craft` | 现有六类造物 ID |

同一摊主每种货架列一次，省略 `ids` 即经营全类。商品的原价、库存、解锁与结算均取自现有系统。同一种器料可以在多个摊位销售，购入后进入同一库存。当天没有可陈列货物的摊主会隐去。不同交易规则或全新货类需要另外接入。

桌面最多三位出摊时并排显示摊牌，四位及以上使用摊主名录。手机从顶部「换摊」选择摊主，「回丹坊」随时可用。

商品陈列在画中的木架和柜面上。点实物或它的小签即可查看用途、价格和库存。再点旁边的货物即可比较，只有按购买键才会付款。常规购买后仍留在原货位，已购法器可由「回炉布置」带回丹房。手机底栏并排显示余额与购买键，器料的「详情」内可看估价、求购条件及取料入口。

每盘最多摆三件，同类商品更多时出现「换一盘」。往返于同一货架的不同盘会记住刚看的货物，换摊或换货架则重新选货。周掌柜的柜面同时陈列成品样件和器料包，小签与购买键结算的是一份器料。接受法器商邀请仍会直接看到避火佩。
