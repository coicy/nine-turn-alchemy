# 丹坊柜台来客交易

法器商在玩家结清前两单后携避火佩、镇炉印、调息盘和鸣金铃来访。点柜上的实物，金色边框会标出所选法器，柜台下方会显示名称、售价和效果。买下后可回炉布置，首访也可选一件留到当日收市。回到接待柜台，点写有法器名字的「取」按钮可按原价取走。回访携带的改炉图样同样可以点选查看。

## 来客安排

| 来客 | 到访与货物 |
| --- | --- |
| 法器商 | 首访后隔二至三天带货。从已开放、尚未购入的法器中随机带最多五件。炉具仍可改良时会额外带来改炉图样。货物在同一柜面陈列，窄屏分前后两排。 |
| 周掌柜 | 从六类造物中抽两样，柜面同时摆成品样件与器料包，成交后器料入匣。 |
| 何采药 | 来访时带普通药包和精选药包，精选药包由42文降至36文。普通药包剩零或一包时，可在柜台或空闲备药匣叫货，每包18文。主动叫货只供应普通药包。 |

首访后的自然来客在当天处理一至三单后出现，每日最多一位售货来客。出售成品的求购客、炼丹委托各有自己的队列。买货、留货和送客均不修改委托总数。药包叫货和当日取留货由玩家主动发起。经营簿的「经营概览」保留寄售账目。

来客、当天计划、货物、选中项和留货都随经营存档保存。旧版正看法器的存档会在柜台接续。基础价格、法器解锁日、器料用途、买入记账和收市租金由原经营系统结算。

## 后续增加商人

在 `market-merchants.js` 的 `merchants` 中登记商人名称、立绘、最早来访日 `fromDay` 及生成当次货物的 `pack(campaign)`。普通来客从已开放人选中抽取，尽量与上次不同。已有类型包括 `tool`、`craftMaterial`、`material` 和 `furnace`。法器商另用固定首访及回访间隔。
