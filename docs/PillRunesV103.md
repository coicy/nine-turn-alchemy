# 丹体与生长丹纹 V103

2026-11-06。制作人确认丹纹形状区分与同纹持续生长方向，授权接入本游戏。本轮接续独立炉前 V102，不改经营、概率、配装、同纹去重或六纹上限。

## 玩家可见变化

- 炉前丹体按屏幕尺寸校准：手机44 CSS px、桌面88 CSS px。取放目标与丹体分开，手机至少48 CSS px；炉内、拿起、取消、落盘保持同样尺寸与外观。炉体、相机、盘的位置延续已验收构图。
- 丹体改为安静的哑光表面。六种丹纹采用火焰、流水、月弧、折雷、相生双弧、月星组合的独立轮廓与辅助色。最新一道占据主要观察面，其余沿周边陈放，保留间隙。
- 同一种丹纹随真实转数持续扩大主纹、凝实轮廓并伸出支脉。四个观察阶段为1–9转初显、10–29转凝实、30–59转分枝、60–100转贯通；各阶段之间仍连续变化，百转前不会固定成一张图。
- 品质影响光泽与刻边的凝练。炼化后的纹路短暂显亮，受损短暂失光，随后显示实际转数与品质对应的最终状态。减少动态模式直接显示最终结果。
- 支脉不另算一道丹纹，也不增加效果层数。融合、六纹容量、同名去重继续由原业务规则决定。没有增加“抽到重复纹”的事件或额外奖励。
- “看丹”增加同一颗丹的128px观察图；丹匣、候选、炉谱使用同一渲染来源。成品保留实际转数、品质、药性和纹样，收丹不会把成熟丹恢复成初显纹。

## 美术与接入

- 美术母稿与两张已审参考在 `Art/PillRunesV103`。底图由内置图像工具生成，透明边缘经检查；运行图为512px透明WebP，来源与提示词见 `assets/pill-runes-v103/PROMPTS.md`。
- `pill-runes.js`保存可编辑纹样曲线、色彩和生长投影。生成图提供丹体材质，曲线负责跨转数、跨纹样组合的连续变化，避免为每个存档组合制作独立成品贴图。
- 背景、绘制、持物与落点继续使用原物件几何；新增 `visualDiameter` 与命中矩形共享中心。没有仅缩图片而保留错误取放位置。
- 所有外观由已有业务状态重建。临时显亮不入存档、不改材料和结算；切页与刷新不重播炼化。缓存有48项上限。
- 新底图纳入关键素材预加载，缺失时阻止进入，恢复加载后可重试。旧资源保留，不删除历史母稿。

## 验证

独立浏览器与测试存档用于稀有状态，不访问制作人的浏览器存档。证据根目录为 `Evidence/PillRunesV103`。

- `Local/report.json`与`Extended/report.json`复用双视角及业务回归，覆盖六尺寸、取放、融合、选纹、保护、百转、刷新与重复输入。
- `Surface/report.json`覆盖六类形状、四段生长面积、身体不膨胀、读档恢复、阅读返回、同名去重、图库与背包一致性；对应截图保存当次状态。画面记录会跳过有限的呈现动画，以免把进场遮罩误当稳定画面。
- `Compatibility/report.json`覆盖完整三幕、触摸模拟、减少动态及新素材加载失败与重试。
- `core.json`复用概率、经济、背包、丹纹、装备、存档和30天等九组既有检查。
- 线上重复检查与发布文件比对另存，不覆盖V102的历史证据。

44px主视图用于辨认主纹与整体成熟度；六纹的逐项效果由主动查阅承载。触屏真机和新玩家理解仍为独立未验收项。
