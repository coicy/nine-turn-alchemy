# 炉沿判断条与物件引导 V105

2026-11-06。制作人确认炉边图例并要求实施。当前版本把判断信息移到炉口下沿、火门上方，移除旧常驻操作说明，沿用V104由玩家决定离开炉前的规则。

## 实际行为

- 顶部保留丹房返回、炉前名称、看丹、炉谱及设置。转数、丹值、当前归属和余客料改由炉沿判断签表达，不再占据顶部。
- 五类概率读取真实业务状态，保持红／橙／绿／蓝／紫和未舍入比例色带。展开时显示五类数值；收起时仍保留当前读数，并显示炸丹风险与实际护丹状态。炉谱提供完整规则。
- 同炉阅读、暂回再入保持概率开合；新炉默认展开。持丹时冻结场景与判断签的占位，开合概率不移动盘中落点。
- 手机判断签放在底部，按整个判断签的实际高度保留空间，顶部不再重复读数。选纹、阅读与本炉结束时撤下判断签，避免盖住候选、阅读入口或收据。
- 左下旧教学笺退出。首次取料、投料、催炼和取丹采用真实物件描边及一句短提示；持物时标出当前目标与取消方式，放下即撤。收丹结果继续直接留在炉前，主动返回、迎客或继续自炼才离开。
- 引导按真实拿药、投入、炼化、收丹和离开事件完成，不从日期、收入或转数推测玩家已学会。偏好随当前存档槽保存，设置可关闭或重新查看；关闭教学后，持物目标仍可见。
- 真实受阻原因继续按上下文出现，电脑移至炉右下方，手机放在底部判断签上方；不恢复旧的常驻教学段落。
- 手机空余地面使用同一炉前素材的无物件地面延续，修复误用旧丹房地面形成的横向拼接。

## 兼容与验证

材料、概率、成丹、法器次数、丹值和报酬仍由既有业务状态提供。本次只新增当前槽位的引导偏好，不改变经营存档版本，不改计价、六纹与三装备位规则。

`Evidence/FurnaceSideV105`保存同次输入、状态与截图：

- `Local`／`Online`：六尺寸判断位置、完整文字、真实概率、展开收起、物件引导、键盘取放、旧偏好、三件法器及收丹停留。
- `StayRegression`／`OnlineStayRegression`：委托累计、成功与失败、自炼入匣、重复结算保护、阅读返回和主动离开。
- `Extended`／`OnlineExtended`：选纹、查阅返回、护丹、融合、百转、快速输入、无效释放、失焦及调整窗口。
- `Compatibility`／`OnlineCompatibility`：三幕开场、触摸模拟、减少动态、关键素材失败和重试。
- `core.json`：九组既有业务、经济、存档和30天经营检查。V104计价专项继续通过13组。
