# 九转丹坊 V92：统一桌案透视与结算退出

2026-11-05。针对制作人截图的四项反馈实施。V91的位置与命中检查没有证明器物透视一致，本轮以实际桌面绘制为基准重新处理。

|反馈|处理|
|---|---|
|桌与器物视角不统一|桌面、平放书册、空丹匣、浅青瓷盘与三个承座按同一相机绘成桌面／手机两幅场景。撤下旧书册立面、丹匣图、盘贴图及悬空承座。点击与落盘目标与新画面同步；已装法器继续独立显示、按新承座贴合。|
|离场仍留结算面板|结算显示按本次炉次管理；迎客、自炼、切地点或进入阅读时撤下，返回炉前不重开旧单。新委托结束可产生新的结契，经营数据与奖励不受影响。|
|收据直接显示|取消“查看收据与留言”折叠，直接呈现完成对象、工钱、加赏、赠药及留言。|
|面板游戏风格|新制陶炉云纹、草药淡墨、朱印与旧木压框底板，接入结契、法器说明、丹详情、确认与菜单；内容仍由游戏绘制。|

先向制作人展示生成构图与面板，再接入游戏。手机保留全部桌面物件的稳定构图；书册叠放为一个物件入口，点击后选择经营簿或炉谱。丹匣的真实库存数量仍来自经营状态，背景绘制空槽，避免画面虚构持有丹药。

素材使用内置图像生成工具制作，位于`Prototypes/九转丹坊MVP/assets/workbench-v92/`，提示与来源见该目录`PROMPTS.md`。原V86资源保留。

验证记录归`Evidence/WorkbenchV92`：四尺寸48张基础实画、49种状态共196张页面回归、17项结算退出与命中检查、31项法器操作与24张画面、九组业务回归。最终器身接触位置另外重拍；自动断言与实际透视画面分别判断。

本轮未新增经营规则、奖励、装备槽或存档格式。真机触屏与新玩家理解仍未验收。
