# 开场与前期信息层级 V54

日期：2026-10-31。依据制作人确认方案：保留三幕故事，先看懂一炉，再认识接单与经营。取代 V53 将演出缩为一幕和首单后完整展开功能的方案。

## 体验调整

1. 开始页移除重复委托信；三幕依次为开张、来客、开炉，第三幕按钮衔接实际投药。支持任意幕跳过，继续经营不重复演出。演出不自动推进。
2. 炉旁保留当前丹值、下次炸丹概率、收丹后交付判断；转数与已交/未投药材为次要读数。品质、药性和丹纹能力在详情中查看。活丹期间隐藏重复委托笺，结算提示置于观丹卡下方。
3. 开局提示跟随投药、炼化、取丹、炸炉和结单；选择丹纹、拿起物件与等待炼化优先使用各自操作说明。保留原随机规则与自由收丹选择。
4. 第一天默认简洁导航：首单结束显示柜台；获得报酬或余药才提示坊市，已有法器显示配装。经营簿、炉谱和其他功能始终可经“查看全部功能”访问；既有手动展开偏好继续有效。第二天起完整导航。没有修改经营存档结构。
5. 柜台第一天默认突出当前/下一份待接委托，按钮可展开其他来客；不会选中上一份已结单来笺让新手停住。结算主按钮“接待下一位客人”，赠留余药的自炼为次要选项。
6. 坊市实际场景仅列当前已开放/已购法器，初次购料突出普通药包；赠留余药尚未自炼时说明从药匣取用。法器详情沿用价格与能力单源。
7. 首次点击收工才解释未接委托跳过且不计失败，再次点击确认日结。不会丢弃进行中委托或活丹。
8. 窄屏推荐来笺适度调宽，减少目标和报酬逐字换行；炼丹场景仍沿用固定构图缩放。
