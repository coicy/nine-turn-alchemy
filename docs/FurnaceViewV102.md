# 独立炉前视角 V102

2026-11-05。实施依据为制作人确认的 V101 独立炉前方案及四批实现计划。炉前保留三件已装法器实物，只读查看并响应自动触发。

## 交付行为

- 丹房全景负责取料、经营与配装。投料成功进入炉前，稳定判断阶段可暂回丹房，通过炉口“回到本炉”继续。
- 炉前使用专用俯视近景。合盖扇火后真实结算，揭盖观察釜底丹药；点击拿起再点盘、拖放、键盘均使用同一收丹判定。
- 丹体底色、品质与丹纹、五类实际概率、交付进度及自炼售价全部来自游戏状态。保护、生纹、融合、选纹与百转继续使用现有业务规则。
- 收丹立即交付或入匣，落盘呈现后最多650ms返回丹房，可跳过；炸丹同样返回。减少动态模式直接显示结果。
- 暂离与阅读返回保留本炉，持物时冻结布局；窗口尺寸变化安全放回。刷新恢复最后稳定业务状态，有活丹回炉前，待选丹纹继续选择。

## 资源与实现

桌面和手机分别使用独立构图。固定背景与透明炉盖分层，动态扇子、丹体、丹纹、阴影、火光、法器和输入目标从当前物件几何读取位置。炉盖、扇子、盘、丹体、法器承托已经按实际画面检查。

窄屏案后法器采用两后、一前的错位陈放，三件均有完整44px点击范围。第一版手机横排的第三件曾超出屏幕，已在发布核查中补正，并加入逐件边界回归。

路由在现有 `work` 下增加 `workMode: room | furnace`，阅读返回栈记录视角；原 `navigate(view)` 调用继续有效。材料、奖励、概率和装备次数仍由原单炉业务结算，经营存档格式继续为版本1。临时持物、阅读和炉前演出不写入经营数据。

新资源在开始前预加载及解码；关键资源失败时提供重试，进入经营和扣料均被阻止。资源母稿在 `Art/FurnaceViewV102`，运行资源和生成提示在 `assets/furnace-view-v102`。

## 检查与证据

- `Evidence/FurnaceViewV102/Local/report.json` 记录六尺寸、正常输入的双视角回归与截图。桌面1440×900、1280×720、1920×1080、2560×1440，手机390×900、360×800。
- `Extended/report.json` 使用独立浏览器和明确标注的测试存档，覆盖三件法器、只读说明、灵性选纹、查阅返回、护丹、融合、百转、快速重复输入、失焦取消、重排冻结、键盘收丹和自炼入匣。
- `core.json` 记录原有单炉、30天经营、经济、丹纹组合、法器、多存档、试玩数据、成长与模拟操作九组回归。
- `compatibility.json` 记录三幕开场、键盘投料、浏览器触摸模拟，以及关键资源失败时的操作保护。
- 物件几何和流程断言与实际画面分别检查。真实触屏设备、新玩家理解仍为未验收。

生成拆件的局部陶面细节存在美术重绘差异，当前按同一母图坐标校准外缘、承托与落点；炉盖开合采用即时状态切换，扇火保留短动作。三幕开场原有专项及其他P2条目继续分别记录。
