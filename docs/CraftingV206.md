# V206 自购炼物与偶发求购交付

2026-11-21。按制作人确认的V03方向实施：炼丹保持主业，其他造物采用市场自购器料、自主开炉、普通出售及偶发成品求购。入口为发布主线`Prototypes/nine-turn-alchemy-github/index.html`，不是旧MVP副本。

## 已实现的经营行为

- 坊市新增“器料”分区，六类各有明确价格、库存、初阶出售估值和风险说明。购买只扣钱并增加器料；与其他物料一样，实际投炉才消耗一份，取消持物不扣料。
- 无进行中炼丹委托且炉内已处理时，可在炉前从备料匣取自购器料投炉。一次开一炉，沿用现有五类结果、炉险、法器与敕火符机制；不生成自炼订单，不发客料。
- 造物有六条成长线，各五个可辨认形态。形态在1/3/6/9/15转变化，转数上限仍100；图片根据真实转数选择，受损回落同步退档。没有独立耐久、战斗或建筑模拟。
- 所有收取物进入统一收纳匣。造物可以保留、出售或按原寄售规则寄售；不能提交炼丹委托，也不能当药铺求购的丹药。普通丹药累计药力与工钱规则不变。
- 偶发求购第3天起每天最多一位，以当天订单与日期的稳定散列判定约28%出现机会，不消费炼丹随机数；不是每三单固定任务。只在经营空档来访，法器商优先；不占正常炼丹订单、不阻断活炉。
- 买家只求一件指定品类、至少3转的现有成品，按普通报价加25%买断，不提供材料、不发代炼工钱、不收订金。可以拒绝或缺货离开，均不计委托失败。成交只移除选中物、付款一次，之后恢复正常接待；当天不再重复求购。收工后未成交求购过期。
- 原料库存、活炉品类、器料成本、成品、求购状态均在当前槽保存。市场、在炉、收纳与求购阅读中刷新可续接，不重复扣款或发料。
