# 九转丹坊 V89：逐页 UI/UX 整改交付

2026-11-04。对应 V88审查，82项已完成内部整改验收，三幕B01–B06六项继续暂缓。可检索对应表见 JSON。本报告不将流程正确视为真机或新玩家理解通过。

## 交付结果

- 第一批：独立丹详情、长短阅读层、菜单互斥、上下文确认、出售清空选择与焦点返回。
- 第二批：持物提示、真实药包封签、概率阅读分层、选纹效果与查阅返回、短收据、原位法器说明及共用换装校验。
- 第三批：待接客统一、落印交接、真实日结分类、先选货再开价签、先选丹再出售。
- 第四批：启动页减法、共用数据设置、累计经营概览、真实丹纹图录、限定本次炉讯、存档返回与独立重开确认。

## 贴图落位与文字完整性补查

手机书册与丹匣补上案边搁板，持物时暂退旧交付凭据；法器图相对针座、承垫和支架重新落位；丹匣名与数量合并为前沿单签。炼化光效、火门反馈与绘制命中共用几何，离开场景清除落盘残影。柜台禁止聚焦造成横向场景位移，日常来笺即时完整显示，演出保留原表现。手机读数、风险、属性和选纹按实际高度避让；修复已结单后持药提示被错误隐藏。按钮检查采用实际CSS显示尺寸，补足桌面缩放后的概率重开与查阅入口。

## 验证证据与限制

- 逐页输入、状态、画面与检查：36项断言，49种状态×4尺寸，共196张；检查1440×900、1280×720、390×900、360×800。扫描所有捕获状态的非滚动容器文字裁切，并检查可见可操作目标实际不小于44px。
- 贴图与文本几何补查：61项断言、28组画面，覆盖器物承托、来笺、药包、持药、风险与坊市。几何扫描辅以实际截图检查，不宣称发现所有可能的视觉问题。
- 业务回归：9组既有检查，包含30天经营、概率与丹纹、材料归属、经济、法器、存档、试玩同意与场景规则。
- 浏览器专项原始输出：4组全部通过。专项复用物件、概率、背包与开场检查，保留原概率颜色／比例、收丹只结一次、存入不加钱、出售才结算及槽位隔离。详细报告和截图在同目录Regression下。键盘、触摸模拟、减少动态分别覆盖。
- 主流程使用正常UI点击拖动，固定随机数用于可复现成功路径；受损、炸丹、无效释放及重复输入由物件与概率专项补查。旧档用真实经营所得存档去掉新增可选显示字段，不造材料或铜钱。
- opening-story.js与发布前版本逐字节一致；未实施三幕六项设计整改。新增日结汇总和炉讯上下文为可选字段，旧历史缺项显示“未记录”，不迁移或虚构经营历史。
- **触屏真机与新玩家理解：未验收。** 浏览器设备模拟不能替代这两项。V85独立删减清单继续保留历史待处理状态，不借本轮覆盖项直接结项。
