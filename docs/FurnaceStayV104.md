# 炉次结束停留与后续界面方案 V104

2026-11-06。根据制作人最新要求，本轮直接修正自动离开炉前；新引导和PC概率位置先给出可交互图例，沿用先审后做的约定。下列两项待审方案尚未接入线上游戏。

## 已实施：由玩家决定离开炉前

- 取消收丹、炸丹后的定时返回，包括减少动态模式的立即返回。结算仍在落盘时生效，等待、阅读、重复点击均不再发放材料、丹药或铜钱。
- 收丹后本炉丹药留在盘中，可点盘或“看丹”查看同一颗丹；阅读关闭返回原炉前和入口焦点。炸丹后釜内为空，不提供查看已毁丹药的入口。
- 本炉结束撤下五类未来概率和“催炼”操作标记，不在空炉里展示破折号概率或投料教学。
- 订单未结束时，短凭据显示当前累计和余客料，主动选择“回丹房取料”才离开。订单完成、失败和自炼结算沿用真实凭据与既有下一步入口。
- “继续自炼”明确回到药匣；“接待下一位”明确前往柜台。离开炉前撤下旧凭据，新炉重新展开概率。
- 顶部“丹房”在本炉结束后可用；持物、催炼、选纹仍沿用原操作保护。
- 刷新继续按稳定业务状态恢复：有活丹进入炉前、无活丹进入丹房，不保存或重放呈现动画。本轮不新增存档字段。

## 待审：适配双视角的新引导

采用靠近当前动作的短笺和目标描边，每次只说明一件事，不增加独立教学页面。图例初始展示炉前，可操作火门、拿丹、落盘；也可返回丹房试取料。

| 触发 | 引导内容 | 完成或退出 |
| --- | --- | --- |
| 首次在丹房备料 | 从药匣取一包药 | 实际拿起药包 |
| 持有药包 | 投入炉口，投入成功才扣料 | 成功投入；取消则回到取料 |
| 首次进入炉前 | 先看下一次概率；火门可催炼，也可直接收丹 | 实际催炼结果落定，或主动取丹 |
| 首次取丹 | 拿起丹药，点盘落下；也支持拖放和Esc放回 | 有效收丹；取消则回到判断 |
| 首次本炉结束 | 结果留在炉前，下一步自行选择 | 主动离开炉前 |
| 首次出现选纹 | 选择一道，炉谱可以查阅 | 真实选择成功 |

- 以真实完成事件推进，不以“已有收入”“转数大于一”推测已学会。新版引导采用独立的槽位偏好；旧存档从当前可执行动作开始，不重播三幕或强迫重新炼制。
- 可以收起，设置中可以重新查看。只保留一条提示，受阻原因和持物目标优先；炼化、选择、阅读期间不遮挡丹体、候选或操作路线。
- 只教既有动作，不增加必须点击“下一步”、强制炼化或必经阅读。图例只演示布局和提示推进，不连接经营存档或模拟实际炼化数值。

## 待审：PC概率移入顶部判断带

建议把当前读数与下一次概率放在同一判断区：上排是转数、丹值与归属，下排是五类数值和真实比例带。概率区放在场景外，不压住桌案、法器、丹药和收丹盘。

- 五类、固定颜色、真实比例与独立开合继续保留；不是只保留一个“成功率”。展开时不重复风险摘要，收起时显示摘要；规则主动查阅。
- 与现有右下窗提供可视对照。推荐顶部判断带；不引入第三种炼丹镜头，不改变炉体、法器或收丹功能。
- 仅调整PC。手机沿用底部概率与实际高度留白，不把桌面横条缩进竖屏。
- 持物期间锁定场景几何；开合概率不能把落点移走。释放或取消后才允许重新分配空间。
- 细化实施前应复核1280×720的实际场景大小和88px丹体；不能只移动概率图片，也不能以图例代替真实游戏验收。
