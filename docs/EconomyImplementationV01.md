# 收入、购料、自炼与成长 V01

本轮用户授权将购料、法器与丹炉升级接入MVP。经济与30日经营一同存档，不引入账号、实时市场或配方树。

## 归属与收入

开坊本金80铜钱。委托免费提供三包材料，成丹与余料归客人，失败免赔。成功工钱=30+四舍五入(目标×0.15)；加赏由已交成丹品质、四转以上转数与丹纹数量累计，最高不超过基础工钱。结算标记避免重复发钱。

自购药包一包一炉，收丹即出售；售价=丹值×0.55与丹炉保底价取高，单颗上限650铜钱，炸炉无回款。与客料订单隔离，炼制时不能切换订单。

## 坊市

| 项目 | 价格 | 效果 |
| --- | --- | --- |
| 普通药包 | 18 | 基础起炉 |
| 精选药包 | 42 | 起炉品质提高一档 |
| 灵性药包 | 70 | 本炉首次成功炼化时提供两道丹纹候选，选择后才能继续或收丹 |
| 镇炉印 | 240 | 永久拥有，每炉首次炸炉改为受损；原丹纹护丹优先 |
| 引纹针 | 300 | 永久拥有，每炉重抽当前末道丹纹一次，接受新结果 |
| 精炼铜炉 | 360 | 每炉首次受损的价值扣减减半，转数回退规则不变 |
| 凝丹炉 | 再付900 | 继承前项；六转以上自炼丹出售底价=100+转数×20 |

法器只能空炉切换，每炉同时装备一件；丹炉空炉升级。全部是铜钱内购而非真钱付费。自炼目前统一平性，不扩展材料配方或八种药性。

## 日结与存档

每日仍生成7–8单，允许结束当天时跳过未接委托。进行中的委托和活丹必须先处理。跳过不计失败，不发工钱。30日总评展示累计收入与余额。旧存档在首次恢复时补经济状态，不重新发放已有本金；新购库存和支出随存档恢复。
