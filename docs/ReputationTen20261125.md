# 十点声望规则

日期：2026-11-25。依据：制作人指定上限10点、未完成减1、完成加2。

## 目的与数值

面向30日短篇经营，让失败清楚可见，同时允许靠成功委托恢复。初始10点，上限10点，下限0点。已接委托完成加2；已接委托材料用尽仍未达标、或主动终止，减1。单颗炸丹不单独扣声望，同单只结算一次。超出上限的奖励不储存，账目记录实际变化。

## 来客与结束

7–10点每天7–8位；4–6点每天5–6位；1–3点每天3–4位；0点立即触发游戏失败事件（alchemy:game-over，reason=reputation），结束本局。非零档位只影响下一日来客；一旦归零，立即结束当日与本局，停止接单、炼制和交易。

沿用：未接委托收工标记跳过，不扣声望；声望归零立即失败，不等待收工或次日开门，也不能通过其他委托恢复。失败当日记入经营历史，未接委托归档为跳过；刷新仍为失败结局。第30日收工结束全局。

例：10→失败9→失败8→完成10；5→失败4→失败3→完成5；1→失败0，立即触发经营失败，不再允许接单补救。

## 旧存档

未标记量表的旧档按100点制一次换算：正数除以10向上取整，0保持0；100→10，69→7，39→4，1→1。加入reputationScale=10，刷新不重复换算。保留旧日历史原数值并标注其100点量表，不改已有委托、钱款、物品。当前日已结算委托的历史声望增减保留来源量表，日结统计按新量表折算，不重新发奖扣罚。

## 体验预期

一次成功抵消两次失败；不考虑封顶时，成功率1/3是平均声望变化的零点。这是规则期望，不能保证玩家通关。10点缓冲意味着连续10次整单失败耗尽声望，比原100点减3的连续失败容忍量更低；恢复则更快。每天可提前收工，不以全清委托强制延长时长。

## 制作人重平衡修订（2026-11-26）

- **初始声望调整为 `5 / 10`**（保留上限 10、完成 +2、未完成或放弃 -1、归零立即失败），使第 1–3 天存在真实口碑建立过程并自然衔接高全 `reputation >= 6` 来访门槛。
- **每日来客单量压缩**：7–10 点每天 **4–5** 位；4–6 点每天 **3–4** 位；1–3 点每天 **2–3** 位；0 点仍为立即失败。
- **阶梯铺租**：第 7、14、21、28 天分别为 120 / 280 / 440 / 560 铜钱（总计 1,400 铜钱），单笔基础工钱微调为 `36 + round(target * 0.16)`。
