# 游戏循环与界面衔接修复 V41

日期：2026-10-30。范围：Web MVP；已同步 GitHub 发布副本，试玩压缩包未更新。

## 计划与完成结果

1. 炼丹内选纹：从坊市迁回炉旁候选卡，选择后焦点回到炼丹场景；恢复存档有待选丹纹时也回炼丹现场。
2. 收丹预判：委托显示收后累计交付值及是否达标，自炼显示当前实际售价；未投药材单独显示。售价预览和实际出售共用计算函数，不改经济参数。
3. 观察区取丹：放大的丹药支持点击拿起或拖到收丹盘，保留炉口取丹。键盘加入扇火动作，保留取丹选项。
4. 结单承接：炉旁展示工钱、加赏和赠药，失败说明免赔及退料；提供柜台与自炼/购料入口。
5. 归属口径：柜台今日提示与日结统一为成功余药赠留、失败退回，不再声称全部余料归客。
6. 侧栏布局：工作区不足1280像素时切换1100像素构图，观丹信息移到左侧、收丹盘内移，点击坐标与可见位置同步。炉内有丹时隐藏暂不可用的备药匣，并保留未投材料数量，防止遮挡观丹卡。
