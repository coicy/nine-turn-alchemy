# 本地存档选择 V01

2026-10-31。用于保留现有进度，同时反复测试完整新开局。

## 使用
- 开始页和游戏顶部均可打开“选择存档”，提供三个独立存档位。
- 空位选择“从头开始”，返回开始页后进入三幕开场；已有位可继续，显示天数、铜钱、空炉/炉中有丹和最近保存时间。
- 每个存档位提供“重新开局”，需再次确认具体槽位后清空该槽；其他槽位不受影响。
- 游戏在安全状态自动保存。切换通过重载返回开始页，清除上一存档的交互与演出状态；炼化、投料及扇风待结算期间不能切换。
- 新手引导的手动展开偏好随槽位保存，新建/重置槽位恢复新手引导。音量与匿名记录设置继续沿用浏览器级偏好。

## 数据与兼容
- save-slots.js 在 app.js 前加载；三个槽位各自使用 alchemy-slot-v1-1/2/3，当前选择使用 alchemy-active-slot-v1。
- 槽位外层版本为1，包含原游戏快照、保存时间与引导偏好；内部游戏快照沿用版本1。
- 旧 alchemy-days-v1 仅在槽1不存在时校验后复制，原始旧存档保留，不删除。槽1重置使用空记录，不会在重载后重复导入旧档。
- 单次 localStorage.setItem 写入完整槽位记录；解析失败或不支持的版本不自动覆盖，写失败显示提示。只支持当前浏览器本地存档，不提供账号或云同步。
