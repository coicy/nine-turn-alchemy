# 丹值公式 V104

2026-11-06。制作人确认丹值公式并要求先应用。本轮只接入计价与必要的阶数记录，不实施待审的重复生纹升阶、满纹抽取、定向升阶或能力强化。

## 统一计价

丹值＝四舍五入〔无纹基价 ×（1＋总纹阶×12%＋金纹25%＋星痕35%）〕。

无纹基价包含现有转数、品质、法器百分比及持续折损；计算过程保留小数，只在最终丹值四舍五入。新基础纹为1阶，首次融合继承两道母纹阶数之和。融合纹的固定加成各只计算一次，取消旧生纹即时×1.18与融合即时×1.08，避免下一次成功重新计算时丢失或重复奖励。

当前生纹仍然同名去重、满六纹停止新增；正常成功25%、大成功50%、定向与法器次数仍沿用既有规则。接口和存档可记录高阶丹纹，但重复生纹升级尚未上线。

## 状态与边界

- 当前丹药新增可选 `runeLevels`（按纹名记录阶数）与 `baseValue`（含现有修正的无纹基价）。这两个字段进入当前炉、收丹记录和自炼丹匣，继续使用版本1存档。
- 每次成功炼化由现有转数与品质重新计算基价，再统一计价；受损只扣基价并降转，不扣纹阶。
- 燃纹移除整道基础纹及其计价贡献；烬金印对基价应用原有15%/30%修正。回纹保留原阶数；返生鼎符持续折损继续生效。
- 旧活丹维持已保存丹值，按已保存丹值反推基价，刷新不改变收益。缺少阶数字段时，基础纹按1阶、融合纹按2阶补齐；旧规则禁止同名叠层且融合来自两个一阶基础纹，因此这是确定的兼容规则。
- 已收丹库存和既往结算不追溯重估，不补发钱、不重放奖励。已有库存缺少阶数时保留原名称；本轮新成丹保留并显示阶数。
- 看丹展示每道纹的阶数，炉谱增加计价规则，未增加常驻面板。外观仍由V103的转数、品质决定，未擅自改为纹阶驱动。

证据目录为 `Evidence/ValueFormulaV104`。`formula.json`覆盖制作人确认的七个算例、生纹/融合结算、跨次成功、受损、燃纹/回纹/烬金、精度、活丹与旧档恢复、自炼入匣与百转结算。原有九组业务回归记录在`core.json`。

本轮验证功能正确性，不代表经济平衡已经通过玩家测试。触屏真机和新玩家理解沿用独立未验收状态。发布提交、Pages部署和文件匹配记录见同目录的发布证据。
