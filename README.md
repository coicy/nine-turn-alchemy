## 历史版本说明

以下保留早期经营版本的说明，旧参数和素材归属文字不代表当前规则。


试玩：[打开丹坊](https://coicy.github.io/nine-turn-alchemy/?v=days-2)。

每天随机 7–8 份独立代炼委托，逐单取药、整包投入炉口、点击催炼、引丹入盘。当日所有订单均完成、材料耗尽失败或明确终止后，主动结束今日，再进入次日。共 30 天，订单总数按实际生成统计，第 30 天日结显示经营总评。

- 一次只接一单，每单三包客人药材；全部成丹归客人，未用材料退还，失败免赔。材料与价值不能跨单混用。
- 每天从十种委托模板无重复抽取 7 或 8 单，各 50%；基础目标 120–300，每五天提高 20，为待验证实验数值。
- 取药和落盘支持点击及拖放。炉内有丹时先收丹或炼至炸丹，再终止订单。投药、落盘、催炼过程中不能切单。
- 不自动跳日。订单失败也能继续经营，不使用宗门认证或赔偿惩罚。
- 本浏览器自动保存。刷新后点继续经营恢复；重开经营需再次确认。无云存档，禁用本地存储时无法保存进度。
- 数据收集默认自愿开启，见 [试玩数据收集说明](data-policy.html)。开场演出在点击接单后播放，继续经营直接恢复。

直接打开 index.html 即可本地运行，无需安装依赖。

验证：node verify-mvp.cjs、node verify-simulation.cjs、node verify-campaign.cjs、node verify-telemetry.cjs。经营检查覆盖 30 天随机订单、材料隔离、失败恢复、刷新恢复、主动日结及最终截止；真实浏览器手感仍待试玩。

本次实现不包含报酬经济、自炼库存、炉印成长、账号或 Maker 工程。
