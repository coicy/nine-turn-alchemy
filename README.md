# nine-turn-alchemy

《九转丹坊》是一款单屏炼丹试玩原型。三颗原料内，选择继续炼丹或收丹交付，累计价值达到 300 即完成订单。

## 试玩

下载仓库文件，直接用浏览器打开 `index.html`。支持鼠标、触摸，以及 Enter / 空格炼丹。

开场以“丹坊初启、接到宗门第一份试单”为背景：标题页展示宗门来笺、三份药材和 300 的交付目标；点击“接单开炉”进入游戏。“试炉要诀”可展开阅读，数据收集须自愿勾选。

- 每次炼丹前显示下一次炸丹概率；炸丹会损失当前丹药。
- 赤纹在保持结果后提供一次护丹；青纹减少丹体受损时的价值损失。
- 九转后可收丹交付；原料用尽仍未达标则订单失败。

这是实验原型，规则和数值尚待玩家试玩验证。无需安装依赖；如已安装 Node.js，可运行 `node verify-mvp.cjs` 检查主要流程。

画面采用深青丹房、铜炉与圆形灵丹；品质改变丹色，丹纹环绕丹药显现。普通成功、大成功、融合、受损、炸丹和九转提供不同的动画与价值变化提示。支持窄屏布局及系统的减少动态效果设置。

## 试玩数据

在开始界面阅读 [数据收集说明](data-policy.html) 并自愿勾选后，匿名操作记录会自动上传到本项目数据服务；不勾选也可试玩。右侧可以关闭上传或导出本机记录。断网会本机暂存并重试，服务端根据事件编号去重。

记录覆盖炼丹前的风险和丹药状态、炼丹结果、收丹时机、订单胜负以及重新开始。记录时间包含页面停留时间，不等同于有效游玩时长。数据由客户端上报，适合体验研究，不能当作反作弊或真实玩家人数的依据。

维护者通过 Sites 的数据库管理入口查看 playtest_sessions（含同意版本）和 playtest_events；公众接收接口不提供数据读取。可运行 `node verify-telemetry.cjs` 验证暂存、补传、关闭与导出。

在线试玩：https://coicy.github.io/nine-turn-alchemy/ 。开始界面默认不勾选数据收集；勾选并开始后自动上传。右侧“匿名记录已上传”表示服务端已确认接收，其他状态表示尚未完成。管理者可在本对话要求汇总已收集记录。

`node verify-online.cjs` 会产生以 qa- 开头的少量连通性验证记录，统计真实试玩时需排除。

## 炼丹台操作更新

当前版本：接下委托后，点药包再点炉口（或拖入）整包投药；点击炉膛挥扇催炼一次；点灵丹再点交付盘（或拖入）收丹。Esc 放回手中物件。材料与成丹归委托客人，三包材料内累计交付 300 完成订单。已取消长按蓄火。

运行 node verify-simulation.cjs 可检查实物操作链。
