# 客人角色固定制作流程

生效：2026-10-31。适用：后续全部客人角色及动作。V54 为设计依据。

2026-11-01 补充：角色画风以 `CharacterArtStyleV57.md` 为固定入口，阶段 0、1 必须执行其中的风格与柜台识别检查；V55/V56 不能充当最终视觉母版。

| 阶段 | 必交付 | 放行条件 |
| --- | --- | --- |
| 0 制作卡 | 身份、体型、视角、画风、场景锚点、动作范围 | 一份明确的规格；不混合步行与柜台半身需求 |
| 1 完整母稿 | 一张完整人物透明图、柜台合成 | 头身、肩颈、手掌、衣袖连接与场景比例合理 |
| 2 同源复原 | 分层/蒙皮区域定义、零姿态复原对照、遮挡补绘（如需） | 轮廓、颜色、连接均与母稿一致；无缺块和重复肢体 |
| 3 绑定 | 可编辑骨架、网格、权重及可视化 | 有实际多骨骼权重形变；极限姿态无翻面、开裂或严重拉伸 |
| 4 动作 | 实时预览、关键帧、录制、审查表 | 自然速度和逐帧分别检查；道具接触、遮挡与动作意图成立 |
| 5 游戏接入 | 真实状态触发、暂停/切换/恢复验证 | 演示动作与接单状态一致，无假结算或错播 |

每阶段独立记录：通过、未通过、未制作。仅已验证范围可标为通过。图像未通过就修图，不能以动画遮掩；动作未通过就修绑定/动作，不能以测试通过代替观察。

## 提交用户审查前的强制场景检查

2026-11-01 用户明确要求：新角色生成后，必须先直接放入实际场景比对；内部比对合格后才能提交用户审查，不得把已知不合格稿作为候选方案交给用户筛选。

执行顺序：生成/重绘 → 按真实显示尺寸放入目标场景 → 内部逐项检查 → 修正并重新合成 → 内部通过 → 提交用户审查。涉及多个场景的角色逐一检查；有动作时还需检查实际播放与关键接触帧。

内部检查必须覆盖：
- 与场景和已通过角色的画风、线条、色彩、明暗及细节密度一致；无已知偏离 V57 的未解决项。
- 头身、肩颈、手掌大小、人物位置和视角合理；柜面及道具遮挡正确。
- 正常显示尺寸下角色轮廓、眉眼及神态清楚，符合当前状态的表现。
- 浅底、深底及实际场景中的原图透明边缘干净；不能用显示遮罩掩盖原资产缺陷后判为合格。

每次记录实际场景截图、检查结果及修正项；有任一不通过或未核实项就留在内部继续制作，不得标为「可交用户评审」。没有已通过人物母版时，先按 V57 与正式场景完成内部风格校准，并明确这是首份母版候选，不能把旧失败稿当作合格参照。

提交时以合格的场景效果为主，原始立绘为补充。区分「内部检查通过」与「用户确认」；内部通过不代表用户已认可。失败稿保存在本地过程记录中，不进入正式资源或常规公开候选发布。已发布的历史实验不删除，但保持其历史状态，不能继续作为当前合格候选推荐。

## 单一连续画面的蒙皮细则

不涉及部件相互揭露的微动作，可使用同一母稿的连续三角网格，按头颈、胸背、双臂等区域赋权；所有区域共用顶点与纹理坐标，零姿态应精确复原。该模式无需人为切开肩颈再拼接，也不虚构补绘资产。涉及明显抬臂、放下道具、手指松握等遮挡变化，必须先补绘分层与手型，不得用连续网格硬拉出新姿态。

## 每份样例的制作记录

- 角色规格与本轮动作范围。
- 母稿来源、提示词及本地资源路径。
- 各阶段证据与明确结论。
- 已知限制与未制作动作。
- 发布版本、入口和实际部署状态。

所有新样例默认从阶段 0 开始；以前失败实验不能作为下一阶段的已验收基础。
