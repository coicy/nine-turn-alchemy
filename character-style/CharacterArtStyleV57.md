# 角色画风规范 V57

生效日期：2026-11-01。状态：**角色风格规则固定，最终视觉母版待绘制验收。**

适用于全部普通客人、熟客、人物表情、分层与角色动作资产。承接 UnifiedInterfaceDesignV22.md 的「国风淡彩勾线的市井修仙作坊」，细化人物制作要求；角色画风发生冲突时以本文件为准。固定制作流程仍按 CustomerProductionWorkflow.md 执行。

## 1. 风格定义

**国风淡彩勾线、适度夸张的市井人物。**

人物应像生活在同一间手绘丹坊中的人：朴素、可亲、有年龄和职业痕迹，外形简练，神态鲜明。仙侠身份通过服装结构、随身小物与举止表达，避免华丽装饰压过接待与炼丹操作。

识别顺序固定为：轮廓与姿态 → 脸型和眉眼 → 发式与肩领 → 配色 → 少量材质细节。纹理不得承担主要辨认功能。

## 2. 比例与形体

- 以正常成人结构为基础，头略大；完整站立人体设计参考约 6.5–7 头身，特殊高瘦或矮壮体型可在约 6–7.5 头身内调整。此数值用于完整人体结构，不得直接套在帽顶至大腿的裁切图上。
- 头、颈、肩、躯干、肘腕必须在完整母稿中成立；禁止通过单独放大头部、横向拉伸身体制造变体。
- 体型用肩宽、胸腹体积、颈长、背部弯曲和重心区分；夸张集中在这些大形，保持手臂长度和关节关系可信。
- 不统一成同一张年轻脸。年龄通过脸型、眼睑、眉形、发际、颈部与姿态表达；老人只保留少量结构性皱纹。
- 双手保持可辨的掌形和动作轮廓；柜台正常显示尺寸下，不描满指节、血管和皮肤纹路。

## 3. 线条与明暗

| 项目 | 固定要求 |
| --- | --- |
| 外轮廓 | 深棕而非纯黑，连贯、略有手绘轻重，轮廓强于内部细节 |
| 内部线 | 细于外轮廓，表达眉眼、衣领、主要衣褶与关节，避免密集排线 |
| 明暗 | 每个主要材质以底色＋一层主阴影为主，必要处少量加深；不塑造写实摄影式体积 |
| 水彩 | 轻微的块内颜色变化与软边晕染，不铺满颗粒噪点或脏污滤镜 |
| 高光 | 克制、面积小；皮肤和布料无油亮反光，无眼睛玻璃珠高光 |

线宽校准以人物实际显示约 480px 高的检查稿为参照：外线约 1.5–2px，内线约 0.8–1.2px，作为视觉量级而非机械描边参数。换分辨率同比检查，不能直接将该像素值用于高分辨率源图。

## 4. 脸与表情

- 眉毛、上眼睑、鼻形和嘴角是主要表情线索；眼睛适度简化，但不画成大眼萌系或幼童面孔。
- 面部用清楚的大色面，不画毛孔、密集胡茬、细小皮肤斑点、每一道唇纹或连续细碎皱纹。
- 普通客人也应有不同的默认神态：疲惫、爽快、谨慎、拘谨、精明、安静等，不能统一温和微笑。
- 对同一人物，情绪变化保持脸型、五官位置与年龄一致。不得靠换一张不匹配的脸实现表情。
- 表情需要在柜台实际尺寸下辨认；原图放大后的精致程度不是验收依据。

## 5. 色彩与材质

调色参考（允许同色系变化，不要求每人使用全部色）：

| 用途 | 参考色 |
| --- | --- |
| 轮廓深棕 | #4B382B |
| 米白布 | #E6D9BA |
| 灰青 | #687B76 |
| 赭土 | #A98550 |
| 黯朱红 | #985B48 |
| 墨蓝 | #526371 |
| 紫灰 | #807080 |
| 炭褐 | #514B43 |

- 每人以两种主衣色＋一种小面积辅助色组织；肤色按人物区分，不给所有人套同一种橙褐色。
- 布用色块、领口、袖型和主要褶皱表达，不画遍布织物纤维。皮革用厚薄和边缘表达；金属用少量硬边与小亮面表达，不加入写实反射。
- 不给人物整体套一层棕色滤镜来匹配场景；人物仍需有清楚的肤色与服装色差。
- 默认左上柔和暖光，阴影不比画面主体更抢眼。透明区内禁止光晕、地面影、黑色色块和背景渐变。

## 6. 柜台镜头与识别

- 人物镜头沿用柜台的正面略侧视角与场景透视，避免俯瞰头像、仰拍肖像和人物证件照混用。预览可以统一观察角度，正式动作与朝向允许有设计差异。
- 以柜面到腰腹附近的成人尺度定位；高矮通过完整人物等比缩放和站位校准，头部不得独立缩放。
- 每位客人在柜面以上至少有三个识别点：例如脸型＋发式＋肩领轮廓。不能依赖被桌面挡住的裙摆、鞋或腰包区别人物。
- 职业不自动等于单一配色或一种帽子。相同职业也能有不同年龄、体型与衣装，相同骨架可以对应不同职业。
- 八人同屏检查时须有不同的肩线、重心与手势；握肩带不能成为大多数人的默认动作。

## 7. 与动画制作衔接

- 完整母稿先通过上述规则，再进行同源拆层、遮挡补绘和绑定。
- 纹理要足够简练，避免网格运动时布纹像橡皮一样拉伸。关节覆盖通过真实补绘和权重解决，不增加厚重阴影遮缝。
- 同体型可以共享适配骨架，不等于可以随意换头或换袖子。不同体型分别验证关节、脸和手的尺度。
- 本规范不改变 40 名普通客人＋8 名熟客的内容目标，也不把八类体型等同于八名最终角色。

## 8. 后续画稿验收

每次提交至少包含：完整母稿、实际柜台尺寸、只看柜面以上的截图、人物轮廓检查以及与已通过视觉母版的并排对照。

必须逐项回答：
1. 缩到实际显示尺寸，眉眼和神态是否仍清楚？
2. 遮住下半身和去掉姓名，能否通过上身轮廓辨认？
3. 与其他人物的线宽、明暗层次、眼睛简化程度是否一致？
4. 是否仍有皮肤微纹理、满衣布纹或写实肖像倾向？
5. 肩颈、肘腕、双手和服装结构是否连贯？
6. 在浅色、深色底及柜台上，透明边缘是否干净？仅有 alpha 通道不代表合格；显示遮罩不代表原图清理完成。

任一结构或透明缺陷未解决，不进入生产拆层。风格不一致时先修画稿，不靠动画和调色掩盖。

## 9. 旧稿地位与执行顺序

- V55、V56 保留为人物身份、姿态和技术实验参考，**不作为最终画风母版**。V56 的既有透明残留和写实细节待办继续有效。
- 首批风格校准对象固定为行商、客栈掌柜、婆婆，覆盖中等、丰腴、弯背老年结构。三人对照通过后，才统一其余五人并扩产。
- 本次只固定规则，不宣称三张校准稿已绘制或获得用户验收。规则可以直接执行，视觉母版须另行记录。

## 10. 生成提示词基线

主提示：国风淡彩勾线的市井修仙人物，简化成人比例、头略大，清楚的轮廓与眉眼神态，细深棕轮廓线，归纳衣褶，低饱和大色块，底色与一层主阴影，轻微块内水彩变化，朴素实用衣装，左上柔光，完整人体连接，同一柜台视角，干净透明背景。追加该人物的体型、年龄、脸型、默认神态、衣装结构和动作要求。

排除：写实肖像、摄影皮肤、毛孔、密集胡茬、密集布纹、复杂排线、油亮高光、玻璃眼、幼童 Q 版、偶像美型脸、统一微笑、过量金饰、背景光晕、黑色残留、独立部件拼图。

提示词只是生成约束；最终仍按第 8 节检查，不能因为使用同一提示词就认定画风一致。
