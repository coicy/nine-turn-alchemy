# 定点观察与场景入口 UX V76

2026-11-02。设计提案，尚未绘制新场景或实装。继承V74炉旁可见法器、V75制作人确认的3–6件成长。本文替代V73将顶部三地点导航作为主要入口的提案，其资源准备、业务隔离、书册返回与减少动态规则仍沿用。

## 核心选择

采用固定观察位置的点击式场景交互。玩家在柜台、炼丹房、坊市各有一个工作视角，通过真实可见的通道/店门进入另一工作位置。一次点击直接转移，不加自由走路、门把操作或重复确认。顶栏只显示日期、铜钱和小型设置；地点直达保留在可展开的小型地点菜单中作备用，而非常驻三大页签。

模拟感来自空间用途与操作意图一致，不要求把所有数字也变成难找的装饰。炉中风险与丹值仍是清楚可读的信息，忙碌/锁定有文字说明。法器不成为入口菜单，仍是实际装备物件。

## 入口分配

| 当前地点 | 可见物件/空间 | 一次点击的结果 |
| --- | --- | --- |
| 柜台 | 室内左后侧的炼丹房通道 | 转到炼丹房，保留当前炉与订单 |
| 柜台 | 正面朝街的店门 | 到坊市工作视角 |
| 炼丹房 | 右后侧通向前堂的门洞 | 回接待柜台 |
| 坊市 | 身后/侧边可辨识的回店门口或街道边缘回店标识 | 回离开前的丹坊工作位置，不能每次强制绕柜台 |
| 任一工作地点 | 该处的账册/挂置炉谱或随身书册入口 | 原地阅读，合册回原视角 |

上述空间是新背景绘制要求。现有丹房没有经过校准的对应门洞，不能直接把窗户、装饰墙或整块无提示的屏幕边缘当通道。柜台到炉房的室内动线与出店动线必须视觉分开；前堂来客区域不应暗示玩家要穿过客人身体才能出门。坊市为定点摊位视角，不新增自由行走地图。

## 入口的可发现性

门洞本身有通透的纵深、木框与暖光，首次到场可以给一次很轻的边缘提示。靠近鼠标或获得键盘焦点时，在门口显示短标签“去炼丹房 / 去坊市 / 回柜台”；热点覆盖实际可见通道且留适度容错，不能仅有几像素门把。

默认没有全屏箭头和发光传送圈。空白地面不换景，屏幕边缘移动鼠标不自动切换；点击一个不该移动的罐子也不会触发导航。入口不能被面板或候客挡住。键盘Tab可聚焦入口并朗读地点名，Enter直达；触屏有常驻短门牌，不依赖悬停。设置中可开启全部入口标签，小型地点菜单提供同等直达路径。

## 业务意图优先

首次接单：点身前纸笺→阅读→“落印接下，携料回房”。该动作在接单校验成功后同时领料并直接转到炉房，无须再点门。后续仍可自由点通道返回。旧稿“先接下，再关详情，再点导航”的多步路径不采用。

炼丹中：点火口继续，拖丹到盘收取；不会因柜台来客自动切走。收丹达标后局部结果提示带一个“回柜台接客”入口，允许直接前往，但不强迫回去手动交付。没有活动单且有自有药材可继续自炼，不强行中断。

购置：货物直接陈列于摊台，点货物后就近显示价签，再确认购买。购买法器后提供“回房布置”，材料后提示“已放入药匣”；这些都是当前结果的快捷入口，不构成永久按钮墙。任意位置仍有备用地点直达，不因沉浸要求多走两次。

看书：在当前地点拿起账册/炉谱；阅读信息不触发换景，不重置本炉，也不改变选中的商品/客人。账册的场景物件位置和热点需要与背景共同校准；尚未完成美术时保留清楚的文字书签作为过渡，不能放一个看不懂的角落图标。

## 转场演出

点入口后先在通道处给即时回应，资源已解码才启动约350–450ms过渡。镜头轻微朝目标通道偏转/平移，近景门框形成完整遮挡瞬间后替换背景，再到新工作视角稳定。总画面不能长距离滑移，也不用黑屏遮掉所有内容。场景几何不连通时需补画门口过渡，不能用动效掩盖矛盾。

入口/意图选择决定方向：柜台向左进入丹房、回柜台反向；向前出店、回店反向。不是为每张页面播放同样的淡入。顶层日期/铜钱保持稳定。已布置法器随房间出现，客人与来笺只在真实换客/到位时播放，不因来回查看重播。

忙碌中点击门口显示“本次炼化完成后前往”，可取消；必要显纹选择优先，不能隐藏未读结果。拖动物件时先放下/取消再走；活丹非忙碌时可离开，炉状态完整保留。开门声只在有真实门扇开合资产时使用；空门洞配轻足音/环境声过渡。减少动态直接短切，不影响位置和状态。

## 实施与验收

先绘制三地点入口关系及全景草图，核查门口是否真实可见，再在实际游戏状态下叠加热点；入口和遮挡资产不合格前不替换正式背景。现有V73可点击稿仅表示面板/状态关系，不是本方案最终布局预览。

验收以第一次试玩能否找到去处、接单到投料点击数、往返是否误触、查看资料是否回到原位、火口/收丹路径是否被门口热区干扰为核心。对比旧顶部导航：不能为点门增加必需步骤，不能降低风险信息可读性。核查键盘/减少动态/缺图/快速点击/1280×720/触屏标签；记录未完成项，不将方案文档当作已完成实装。
