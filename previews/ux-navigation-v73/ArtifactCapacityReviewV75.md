# 法器容量与构筑深度核查 V75

2026-11-02。结论：设计目标改为前期3件，经作坊成长扩为4件、最终5件；不再把3件写成全流程硬上限。具体解锁成本/时间需数值验证。当前运行版仍为3件，本次未改数值、存档或槽位实现；V74样稿三件陈设可作为前期状态，不代表最终容量。本文覆盖V73/V74关于固定三件的设计表述。

## 调研证据与边界

- ForgeTax：本仓库../..下ForgeTax/Docs/01_玩法与数值.md“狂热、遗物和商店”确认本地样本8槽、同名上限1、商店3报价、初日三选一。Evidence/provenance.json锁定样本，以上为静态分析事实，不冒充实机试玩。网上第三方指南也描述8槽及满槽后需舍弃：https://www.forgetax.tools/guides/how-to-play 。其内容可能对应不同版本；本项目采用本地样本作容量事实依据，不迁入对方资源或代码。
- Balatro官方介绍强调小丑与扑克牌/牌型共同构成协同：https://store.steampowered.com/app/2379780/Balatro/ 。槽位取舍不独自承担全部深度；不能据其体验直接证明九转丹坊只需3件，也不能把官方未写明的精确槽数当本次核实结果。
- 背包乱斗开发商商店页说明购买、形状、大小、摆放和合成共同影响构筑：https://store.steampowered.com/app/2427700/Backpack_Battles/ 。本游戏尚无相邻/占格规则，摆出更多法器不能直接获得这类空间策略深度。
- 杀戮尖塔官方说明遗物与牌组有强交互、获得遗物有额外代价：https://store.steampowered.com/app/646570/Slay_the_Spire/ 。其深度来自牌组、路线和遭遇的联合选择，不能只比遗物件数。本次不以未核实的遗物持有上限作论据。

这些作品分别是风险经营、协同构筑和空间自动战斗参考，不是玩法完全相同的对照实验。以下结论为基于证据及当前规则的设计判断，未进行玩家研究或3/5槽收益对比模拟。

## 本游戏的具体瓶颈

economy.js现有17件：13件非定向、4件定向，同炉定向最多1件，EQUIP_SLOTS=3。具体效果及独立次数以实际目录/app结算为准。组合说明见design/quick-specs/rune-combinations-2026-10-29.md。

“燃纹盏＋回纹环＋烬金印”已经消耗3位：消耗、回收、变现刚能接通，缺少生纹针或定向支持的位置。“生纹针＋合璧镜＋六合盘”也占满3位，难再添加大成功或升转转化。定向本身占三分之一容量；它不直接产生纹路，机会成本很高。不是三件不存在深度，而是多数链条的启动/维持/收益已经需要三件，后续新法器容易变成替代品而非新的组合环节。

订单主要以丹值达标，材料药性目前主要影响外观；不能把尚未实现的药性策略、特殊客人机制当作现成深度。本地还有六纹随机/融合、转数风险和经济压力，但它们是否足以支撑长期三槽仍未验证。组合数量也不等于有效流派数，价格/开放日/持有量会进一步限制可达组合。

## 决定

1. 前期3件，便于理解物件和第一次自动链；中期4件提供一个修正环节；后期5件允许主链加两个支持/转化件。升级通过作坊布置成长获得，购买与解锁不增添炉内操作；价格、开放日暂不拍定。
2. 五位为通用容量，不固定为“输出/防御/辅助”等职业槽。定向仍同炉最多1件。三件同名不重复、空炉调整、单炉次数及防递归规则继续适用。
3. 法器实物仍布置在炉旁：案面支持3至5个稳定位置，随扩建出现承垫/针座/支架，而非横排五个UI卡框；避免占收丹盘和火口路径。未装备藏品不自动生效。
4. 五件示例：“生纹针＋赤砂引＋燃纹盏＋回纹环＋烬金印”把供纹、方向、消耗、回收、增值接在同一炉中；仍缺少合璧镜、六合盘或其他减险件。只是可测试构筑，不宣称最优或已平衡。
5. 暂不采用8件或无限常驻：当前目录较小、同一资源链较集中，可能把生纹、定向、融合、减险和保护全部装齐，削弱取舍并放大高转收益。未来若内容维度扩展再重新评估。

## 下一轮验证

比较3/4/5槽，以相同种子、相同购买预算、相同材料/订单/炉具分别测：每日完成率、所得分布、失败损失、转数分布、纹路形成速度、每件实际触发频率、保护耗尽概率。短单稳妥、长炉求高转、自炼逐利应分别存在合适组合，而非一套通吃。不得只对比“同17件全持有但不同槽位”的不等价成长曲线。

检查每件是否因槽满永久无用、链条是否真正改变继续/收丹选择、5槽是否让保护近乎无限、组合信息能否在一次反馈中读懂。必要时重设计过强件或失去用途的件，而不是一律提高订单目标抵消升级。未完成这些验证前，不声称5槽已经解决深度或平衡。
