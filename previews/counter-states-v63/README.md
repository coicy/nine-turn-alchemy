# 接待柜台 UI 状态 V63

2026-11-01。已实装于 campaign-ui.js、counter-ui-state.css，由既有经营状态推导，不增加第二份订单数据。固定单屏，委托簿内部滚动，没有整页滚动或暗幕。

| 状态 | 常驻内容 | 操作与物件 |
| --- | --- | --- |
| 柜台常态 | 第几天、今日完成数；当前客人、对白与手书 | 右上委托簿入口显示待接人数；默认不铺开全部来笺 |
| 打开委托簿 | 右侧非模态纸页，列出所有来笺及状态 | 展开/收起、Escape、选择；选笺自动收起，焦点返回入口；打开时隐藏被遮的对白 |
| 待接单 | 客人、手书、目标与工钱 | 柜上显示客人带来的药包和落印提示；不显示无意义的0进度收据 |
| 待接但已有活单 | 可以查看其他来笺 | 落印按钮解释先办妥手中委托，不允许重复领料 |
| 炼制中 | 当前客人与手书、交付进度 | 柜面药包和药包下提示移除；收据说明材料在炉台；可携料回炉 |
| 已完成/失败/跳过 | 手书归档、结果收据与留言 | 无柜面药包，无活人重复留柜；可从委托簿选下一位 |
| 当日结清 | 精简日期与日结结果 | 隐藏委托簿入口、旧客人留言和旧单据，保留迎接次日入口 |
| 经营结束 | 经营总评与经营结束提示 | 不提供接单入口；不宣称新增完整结算美术场景 |

累计完成数不在柜台常驻，保留经营簿查阅；材料归属规则保留在委托书，左上不再逐日重复长规则。待接人数只统计pending；日结跳过、失败与完成仍由原经营逻辑判断。
