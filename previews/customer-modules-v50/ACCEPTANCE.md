# V50 设计与验收

日期：2026-10-31。基线：项目已进入优化制作，沿用三头部、两服装、可选背篓的组件组织；不按MVP压缩目标表现。此轮交付是新风格和静态拼接设计样张，不修改主游戏客人。

## 设计

- 风格：国风淡彩勾线，柔和成人面孔、归纳色块、少量层次阴影，减少皮肤、头发和布料的写实纹理。头略大，服装赭黄/灰青，保持场景木纸色系。
- 接口：头、短颈、米白内领组成一个模块，外衣单独成套。接缝藏到衣领重叠区，不再用延长裸颈硬接无头躯干。
- 手臂与衣袖、手部随服装成套，不在此批强拆。背篓独立置于身后；不同人物仍使用相同中性等候姿态。
- 新素材仍通过CSS叠层实际组合，不将重新生成的完整人物当作组件复用结果。原图保留，不通过代码绘制或修补人物像素。

## 生产与修正

1. components-source.png：六组件的新风格草案。初步组合暴露出相邻躯干互相侵入裁切区、袖口被截的问题，不批准其躯干矩形直接入库。
2. torso-ochre-source.png、torso-teal-source.png：分别重出完整躯干，但带有背景色雾，不作为实际显示源。
3. torsos-clean.png：通过imagegen重新清理背景并分隔两躯干，实际用于预览。三头部与背篓继续来自components-source.png。
4. 组件局部框、缩放与锚点写在preview.html；新躯干使用独立2列图集，避免为了维持单张图集而裁掉人体。保留逻辑组件组织，不要求源文件必须只有一张图片。

## 验收表

| 项目 | 结果 | 依据/限制 |
| --- | --- | --- |
| 十二搭配真实组件复用 | 通过 | 3头×2衣×背篓有无，切换时复用源组件 |
| 成年人物与三种年龄识别 | 通过，限该体型组 | 同一体型、角度，尚无其他体态 |
| 裸颈过长、透明缺口、双重衣领 | 静态检查通过 | 已查看领口放大图及两种服装组合，无上一版明显裸颈拼口 |
| 袖口与外轮廓完整 | 修正后通过 | 首轮失败，使用清理后的独立躯干图集复验 |
| 透明背景 | 使用文件抽样通过 | PNG有alpha，图集角点及两躯干中间透明；未将有色雾的初稿用于显示 |
| 符合淡彩勾线方向 | 有条件通过 | 去掉写实纹理；外衣外轮廓仍比头部略粗，需统一线宽后批量入库 |
| 背篓连接 | 静态预览可用 | 在后层、遮住部分挂带；转身/递物运动尚未验收 |
| 场景尺度 | 仅参考 | 提供柜台画面，统一头顶与站位；未替换真实游戏和真实队列状态 |
| 表情、递包、收丹动作 | 未验收 | 本批没有对应动画资产，不能声明完整动作兼容 |

结论：**新风格与静态拼接设计样张有条件通过，可以进入精修；不作为完整角色生产资产验收通过。** 下一轮先统一头部/外衣线宽，确认本风格，再验证同组表情与递物动作，之后扩展不同体型与剪影。十二套搭配仍只有三个头部身份，不等于十二名独立角色。

## 生成方式与提示词要点

imagegen内置工具。第一轮以炉房为唯一画风参考，明确不使用旧写实人物为画风基准；要求细棕线、归纳色块、简化成人五官，头颈连内领，外袍与背篓独立。后续两次以该稿为参考分别生成完整无头躯干，要求保留双侧袖口和边缘。最终以两张躯干稿作背景移除与打包，要求真正透明、无色雾、无光晕、两图留足间隔。
