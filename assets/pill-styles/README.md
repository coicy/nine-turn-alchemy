# 丹丸材质三案 V07

本轮根据 RealPillTextureResearchV01.md 制作三种整体美术方向。它们是现实丸剂材质启发的手绘游戏化方案，不是对应制剂的实物鉴定图。

三案控制同类药性底色、上品浅蓝凝纹、圆润形态与左上柔光。丹体和凝纹均在完整生成式透明 PNG 内，不使用代码裂纹、叠层或滤镜着色。

- A 细润蜜丸：致密匀净、柔和宽光，细润但不湿亮。建议作为 MVP 全系列的基础风格。
- B 细粉水丸：干爽柔哑、极轻粉感，整体更朴素；注意避免干涩土球感。
- C 微光浓缩丸：均匀表面加克制半光泽，体积清楚；注意控制高光，避免树脂或宝石感。

三者不对应不同品质等级，不把材质光泽与品质混绑。后续仍以丹体颜色区分药性、凝纹颜色区分品质，沿用用户已确定的规则。
